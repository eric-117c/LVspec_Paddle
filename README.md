## Quick Start

### 1. Install dependencies
Create and activate your environment, then install requirements:

```bash
pip install -r requirements.txt
```

### 2. Run
Run the demo script to quickly evaluate LVSpec:
```bash
sh run.sh
```

### 3. Performance Evaluation
To benchmark performance, please integrate file ''evaluation/qwen2_5_vl_lvspec.py''  and ''evaluation/llava_onevision_lvspec.py''into the lmm-eval repository.
